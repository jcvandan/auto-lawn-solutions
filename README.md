# Auto Lawn Solutions

Brochure site for Auto Lawn Solutions — independent robot mower specialists covering Lancashire, the Ribble Valley and the North West.

Live site: [https://jcvandan.github.io/auto-lawn-solutions/](https://jcvandan.github.io/auto-lawn-solutions/)

## Local preview

This is a static HTML/CSS/JS site. Open `index.html` in a browser, or serve the folder:

```powershell
npx --yes serve .
```

## Placeholders to replace

- Email: `hello@autolawnsolutions.co.uk`
- Phone: `01200 000000`
- Facebook URL in the footer and contact page
- Product photos and prices on `mowers.html`
- Installation photography on `installations.html`
